# Codex Manager v0.6.5

## 概览

Codex Manager 现在提供完整的简体中文和 English 界面。首次打开时会自动匹配设备语言；你也可以随时在顶部切换，并在需要时恢复“跟随设备”。

Codex Manager now offers complete Simplified Chinese and English interfaces. On first launch, it follows your device language automatically; you can switch at any time from the top bar or return to the device default.

## 主要变化

- 主要页面、按钮和状态提示现已支持 English。 / Main pages, controls, and status messages are now available in English.
- 中文设备默认使用简体中文，其他设备默认使用 English；顶部切换会记住你的选择。 / Chinese-locale devices default to Simplified Chinese, while all others default to English; the top-bar switch remembers your choice.
- 数字、日期和金额会匹配界面语言，项目名、模型名和路径保持原样。 / Numbers, dates, and currency follow the interface language, while project names, model names, and paths stay unchanged.
