# Codex Manager v0.1.0 — Unsigned Community Build

> 这是面向开发者和早期测试者的 macOS arm64 开源预发布版，不是已签名的正式 macOS beta。

## 概览

本版本建立本地元数据观测、项目发现和安全编辑的最小可用链路。

## 主要变化

- 本地优先观察 Codex rollout 元数据、token、耗时、来源可信度与 API 等价价格。
- 项目与 `AGENTS.md` 集中发现、安全编辑和原子保存；优先展示顶级全局 `AGENTS.md`，项目根目录状态使用绿/黄点区分。
- 用户主动的 GitHub Releases 更新检查界面；稳定在线更新通道暂未启用。
- 可选 TLS loopback OTel receiver、严格隐私边界、SBOM、许可证和 SHA-256 发布证据。

## 重要安装提示

- DMG 没有 Apple Developer ID 签名，也没有经过 Apple notarization/stapling。
- macOS Gatekeeper 显示警告是预期行为；请只在核对本 Release 的 SHA-256 和源码后，按 macOS“隐私与安全”界面手动批准。
- 本 Release 不包含 `latest.json`、updater bundle 或 updater signature，不会启用应用内稳定在线更新。
- 需要无警告安装体验的普通用户，请等待后续 Developer ID 签名并公证的更高版本。

## 完整性

Release 附带独立 DMG、SBOM ZIP、许可证 ZIP 和 `SHA256SUMS-v0.1.0-community`。源码压缩包由 GitHub 根据 `v0.1.0` tag 自动生成；本次 tag 目标提交为 `fb27f64d6f64bbd9a5ee82ae9850082220970229`。

## 验证状态

- `implemented`：本地采集、项目发现、AGENTS 安全编辑和发布证据链。
- `tested`：本地 unsigned 构建、`hdiutil verify`、SBOM、许可证和 SHA-256。

## 兼容性与限制

仅 macOS arm64；不包含稳定在线更新，内部 rollout JSONL 不是公开稳定 API。

## 隐私与安全

仅保存元数据；不保存消息正文、凭据、token 或请求查询参数。
