## Chrome 交互验证

按账号核对后使用既有 `px / Default` 个人资料。Playwright 扩展不可用，使用 Chrome 原生 AppleScript 执行页面 DOM 操作；没有切换到临时个人资料。操作对象为 `127.0.0.1` 上的人工 demo，故障注入仅在页面内存中替代 IPC，不触及真实 Tauri 后端、账户、Keychain 或 Codex 配置。

以下 10 项通过：

1. 未保存草稿取消切换全局 AGENTS 后保留。
2. 未保存草稿取消切换项目后保留。
3. 未保存草稿取消主导航跳转后保留。
4. 未保存页面的 `beforeunload` 事件被阻止。
5. 保存未完成时禁止编辑及导航。
6. 保存成功更新草稿基准并退出未保存状态。
7. 保存成功、revision 刷新失败时同时说明两个结果。
8. 零结果筛选保留已选模型。
9. 从模型交互切换任务汇总时清理 `accounted` 条件。
10. 可见代理页通过周期读取，从人工 `running` 更新为 `error`；展开状态区可见对应错误。

初次代理断言读取 `innerText` 时，错误详情已随异常状态折叠，造成测试脚本超时；复核 DOM 状态并展开详情后通过，无需修改产品代码。此证据证明前端状态同步，不代表真实内核或 OAuth 验收。
